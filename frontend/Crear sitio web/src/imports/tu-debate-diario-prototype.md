Design a web interface prototype for a Spanish discussion platform called:

TDD — Tu Debate Diario

IMPORTANT:
All interface text must be in Spanish.

The platform publishes exactly 5 debates per day about current events. These debates are generated daily and remain featured on the homepage for 24 hours. Older debates are stored and accessible in other sections of the platform.

The goal of the platform is thoughtful discussion about current topics with a healthy community environment.

Users can vote positively on comments to highlight quality contributions. Negative votes are not used.

The layout should be inspired by Reddit but cleaner, more editorial, and focused on debate quality.

Use a three-column layout:

LEFT: main content feed
CENTER: debate feed
RIGHT: navigation and community sections

However, the navigation sections should appear mainly on the RIGHT side instead of the left.

------------------------------------------------

TOP NAVBAR

Minimal navigation bar similar to Reddit.

Elements from left to right:

Logo:
TDD

Search bar:
placeholder text: "Buscar debates"

Right side:

Notificaciones
Perfil

The navigation should be clean and minimal.

------------------------------------------------

HERO SECTION (very important)

At the top of the main content create a large hero section.

Elements:

Main title:
Tu Debate Diario

Subtitle:
Cinco debates sobre la actualidad. Opiniones con criterio.

Below this, display today's date in very large typography.

Example:

MARTES
12 DE MARZO

The date should be visually prominent and centered, almost like a daily headline.

The hero section should feel editorial and calm, similar to a news homepage.

------------------------------------------------

DEBATE TITLES CAROUSEL

Below the hero section create a horizontal carousel.

This carousel shows the titles of the 5 debates of the day.

The carousel slowly scrolls horizontally.

Each item shows:

Debate title
Small comment count

Example titles:

¿Es viable la jornada laboral de 4 días?
¿La IA reemplazará a los programadores?
¿Debe limitarse Airbnb en grandes ciudades?
¿Es necesaria la energía nuclear para la transición energética?
¿Deben regularse las redes sociales?

Cards should be minimal and text-focused.

------------------------------------------------

MAIN DEBATE FEED

Below the carousel show the main debate feed.

Each debate appears as a card similar to a Reddit post but cleaner.

Each debate card contains:

Debate title
Short context paragraph (2–3 lines)
Community position indicator bar

A favor %
En contra %
Neutral %

Number of comments

Button:
Entrar al debate

Cards should feel like important discussion topics, not casual posts.

------------------------------------------------

RIGHT SIDEBAR

The right sidebar contains platform navigation and community information.

Sections:

MENÚ

Debates de hoy
Debates recientes
Tendencias
Mis comentarios
Guardados

------------------------------------------------

VOCES CON CRITERIO

This section highlights the most respected users of the platform.

Title:
Voces con criterio

Each entry shows:

username
reliability score
number of debates participated

Example:

@ana_debate
Índice de criterio: 94

------------------------------------------------

ACTIVIDAD DE HOY

Statistics cards showing daily platform activity.

Comentarios hoy
Participantes hoy
Debates activos
Votos emitidos

Display them as minimal statistic cards.

------------------------------------------------

STYLE

Clean
Editorial
Minimal
Text-focused

Visual inspiration:

Reddit
Hacker News
modern news websites

Color palette:

Light neutral background
One accent color for interaction

Debate position colors:

Verde = A favor
Rojo = En contra
Gris = Neutral

Typography should be highly readable.

The interface should feel like a modern digital public square focused on thoughtful debate.
